# P2-06 — Client setup snippet screen

**Milestone**: Phase 2 — Electron UI
**SPECS references**: §5.3 (Client Setup), §5.4 (criterion 9)

## Goal

A setup screen that surfaces the same snippets `tlbx client print-config` produces, in a copy-paste UI.

## Deliverables

- Client Setup route with a tab per supported client: Claude, Codex, OpenCode, Generic MCP.
- Each tab has stdio and HTTP toggles and a copy button.
- The snippet is generated by calling into `@toolbox/core` (the same code path M5-01 uses) so CLI and UI never diverge.
- Show a short paragraph per client explaining where to paste the snippet (Claude config file path on the user's OS, etc.).

## Acceptance criteria

- The snippet for each client × transport matches `tlbx client print-config`'s output byte-for-byte.
- Copy button writes to the OS clipboard via the Electron API.
- HTTP snippets reflect the live `server.http` config.

## Out of scope

- Auto-installing the snippet into the client's config (Phase 1+ feature; defer until per-client paths are stable).
- Generating snippets for clients beyond the four listed.

## Definition of done

- Acceptance criteria hold.
- Snapshot tests align UI output with the CLI's M5-01 snapshots.
- `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, and `pnpm test:run` all pass.
- Task committed and the P2-06 checkbox in `.agents/TASKS.md` is updated with the closing commit hash.
